## Entry

`main.ts` (Node 22) scores three candidate roasts against the judge's five published criteria — roast of a smart fridge, punchline lands, fridge-specific, tight wording, fresh angle — and writes the winner to `/output/entry.txt`.

The winning line:

> My smart fridge keeps a diary of everything I eat and rates my midnight snacks 'disappointing, but consistent'.

## Run

```sh
node main.ts
```

Writes one line (111 characters) to `/output/entry.txt`. Deterministic, no network, no secrets.
